# Support

- Use [GitHub Discussions](https://github.com/riseagain1/semaframe/discussions) for setup questions, ideas, and architecture discussion.
- Use [GitHub Issues](https://github.com/riseagain1/semaframe/issues) for reproducible bugs and bounded feature requests.
- Use the private process in [SECURITY.md](SECURITY.md) for vulnerabilities.

When asking for help, include your operating system, Node.js version, browser, exact command, relevant non-secret logs, and the smallest reproduction you can provide. Never publish live Agent connection URLs, bearer tokens, feed capabilities, or private project data.
